# usage-bar

Mod do Claude Code: pasek nad polem wpisywania z kontekstem, cache (ostatnia tura i średnia z sesji), limitem 5h, limitem 7d i kosztem sesji.

Limity 5h/7d pojawiają się tylko na planach Pro/Max i po pierwszej odpowiedzi w sesji.

## Instalacja

```
/plugin install usage-bar --marketplace marekdunkel-code/claude-usage-bar
```

Potem `y` (dodanie marketplace) i wybór zakresu (user = każda sesja).
